# Spektrumkollen – synpunkter och felrapportering

Välkommen! Här kan du rapportera fel och föreslå förbättringar eller nya funktioner i Spektrumkollen, en utbildningsapp för att utforska radiospektrum och det elektromagnetiska spektrumet.

- [Rapportera fel eller lämna ett förslag](https://github.com/MrMap/spektrumkollen-feedback/issues/new/choose)
- [Läs och sök bland befintliga ärenden](https://github.com/MrMap/spektrumkollen-feedback/issues)

Du behöver ett GitHub-konto för att skriva. Alla kan läsa. Välj ett formulär och ge ärendet en kort, beskrivande rubrik. Skriv gärna på svenska. Komplettera gärna ett befintligt ärende i stället för att skapa en dubblett.

## Innan du skickar

All text och alla bilagor blir offentliga. Utelämna personuppgifter, lösenord och annan känslig information. Kontrollera skärmbilder innan du bifogar dem. Publicera inte säkerhetsbrister med känsliga detaljer i den öppna ärendelistan.

Spektrumkollen är ett ideellt hobbyprojekt. Återkoppling hjälper oss att prioritera, men innebär inte något löfte om genomförande eller svarstid. Håll en vänlig och saklig ton.

## Vad finns här?

Detta repo innehåller enbart information och formulär för återkoppling. Appens källkod och interna utvecklingsmaterial ingår inte. När ett ärende har bedömts eller en ändring finns tillgänglig återkopplar vi i ärendet när vi har möjlighet.
